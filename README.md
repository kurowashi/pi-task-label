# pi-task-label

複数の Pi セッションを並行で走らせると、どのタブがどの作業をしているか分からなくなります。pi-task-label は、ユーザーが入力するたびに会話の末尾から作業内容を1行のラベルにまとめ、端末タイトルとステータス行に表示します。

```
タブ1: π - 🔧middleware修正 - projectA
タブ2: π - 📝README更新 - projectB
```

同梱の指示文は、作業内容に合う絵文字1つと概要を区切りなしで並べた形を求めます（例: `🔍おいしいご飯の調査`）。絵文字はモデルが選びます。

同梱の指示文は、直近の assistant が次にやろうとしていることを優先するよう指示します。そのため、ユーザーが `OK` とだけ返したターンでも作業内容が分かります。

## インストール

```bash
pi install git:github.com/kurowashi/pi-task-label
```

ref を固定する場合は `pi install git:github.com/kurowashi/pi-task-label@<tag|commit>` を使います。

ローカルの作業コピーを使う場合は次のとおりです。

```bash
pi install /path/to/pi-task-label
```

インストールせずに読み込む場合は次のとおりです。

```bash
pi --extension /path/to/pi-task-label/src/index.ts
```

## 使い方

インストール後は特に操作する必要はありません。ユーザーが入力するたびにラベルが更新されます。

- 端末のタブ名（タイトル）に `π - <ラベル> - <プロジェクト名>` が表示されます。
- ステータス行に `<ラベル>` が表示されます。

前提: 端末（tmux など）がタイトルの変更を表示する設定であること。

## 設定

設定ファイルは次の 2 つです。キーごとに、後のファイルが前のファイルを上書きします。

| ファイル | 対象 | 読み込み |
|---|---|---|
| `~/.pi/agent/task-label.json`（`PI_CODING_AGENT_DIR` で場所を変更） | ユーザー全体 | 常に読み込む |
| `<cwd>/.pi/task-label.json` | プロジェクト | プロジェクトが信頼されているときだけ読み込む（`/trust` で信頼を保存したあと Pi を再起動） |

```json
{
  "enabled": true,
  "model": "",
  "assistantLookback": 1,
  "display": "both"
}
```

同じ内容は [examples/task-label.example.json](examples/task-label.example.json) にあり、そのままコピーして使えます。

| キー | 既定 | 意味 |
|---|---|---|
| `enabled` | `true` | `false` のとき、モデルを呼ばず、表示先からラベルを消す |
| `model` | `""` | ラベル生成に使うモデル（`<provider>/<id>`）。空のときはセッションのモデル |
| `assistantLookback` | `1` | 遡る assistant の件数（1 以上）。本文のない assistant は数えない |
| `display` | `"both"` | 表示先。`"both"` はタイトルとステータス行、`"title"` はタイトルだけ、`"status"` はステータス行だけ |
| `prompt` | 同梱 | ラベル生成の指示文。同梱の既定文は英語。会話の抜粋は自動で後ろに付く |

- `model` と `prompt` は、空文字または `null` のとき既定に戻ります。
- `assistantLookback` は小数点以下を切り捨てます。1 未満や数値以外は警告し、既定値の 1 を使います。
- `display` の値が 3 つのどれでもないときは、警告し、既定値の `"both"` を使います。
- `model` が見つからない、または認証がないときは、セッションのモデルを使い、警告を 1 回出します。
- `prompt` を変えると、ラベルの形式（絵文字の有無など）も指示文で決めます。出力は最初の空でない 1 行だけを使い、連続する空白を 1 個にまとめ、外側の引用符（`"..."`、`'...'`、`` `...` ``、`「...」`、`『...』`）を外し、40 文字（`…` を含む）を超えると `…` で切り詰めます。
- JSON が壊れているか、オブジェクトでないファイルは警告して読みません。セッションは止まりません。
- 信頼されていないプロジェクトの設定は読みません。警告を 1 回出します。
- 設定は、セッション開始時（起動、`/reload`、新規、再開、フォーク）に読み込みます。ファイルを変えたら、`/reload` か新しいセッションで反映します。

## コマンド

| コマンド | 動作 |
|---|---|
| `/task-label` | 解決済みの設定・現在のラベル・読み込みの警告を表示する |
| `/task-label status` | `/task-label` と同じ |

- 表示する設定は、そのセッションが開始したときに読み込んだ値です。
- 設定を変えるコマンドはありません。変更は設定ファイルで行います。

## 仕組み

入力されるたびに、次の 3 段階で動きます。

1. 会話の末尾を抜き出す
2. モデルに 1 回だけ送り、ラベルを受け取る
3. 端末タイトルとステータス行に表示する

### 生成するタイミング

- ユーザーの入力 1 件につき 1 回です。タスクはターン中に変わらないためです。
- 次の場合は生成しません。
  - `enabled` が `false`: モデルを呼ばず、ラベルを消す
  - UI がない（JSON モード・print モード）
  - 入力が空白だけ: 無視する
  - セッションのモデルも `model` の設定も選べない: 警告を 1 回出す
- 生成中に次の入力が来た場合、古い生成結果は表示しません。

### 抜き出す範囲

会話は次の順に抜き出します。

- 本文のある直近の assistant メッセージを `assistantLookback` 件
- その最も古いものより後のユーザーメッセージすべて
- 今回の入力

直近の assistant が 1 件もないときは、ユーザーメッセージすべてを使います。ツール結果・カスタムメッセージ（他の拡張が注入したものを含む）・メタデータは読まず、件数にも数えません。

上限は次のとおりです。

- 1 メッセージの本文: 2,000 文字
- 抜き出し全体: 6,000 文字

上限には `…` を含みます。上限を超えるときは、新しいメッセージを優先して残します。今回の入力は必ず含めます。

### モデルへの送信

モデルには、ユーザーメッセージを 1 つだけ送ります。システムプロンプトは送りません。

```
<prompt>

<context>
Assistant: 次は middleware を直す
User: OK
User (current): OK
</context>
```

- 対応するモデルでは reasoning を `minimal` に固定します。セッションの thinking 設定は引き継ぎません。
- プロンプトキャッシュを使わず（`cacheRetention: "none"`）、セッションとは別の session id で送ります。
- ラベルはセッションに保存されず、会話のコンテキストにも入りません。

### 失敗したとき

- 生成に失敗したターンは、前回のラベルを表示したままにします。
- 警告はセッションで 1 回だけ出します。

### 送信されるデータ

会話の末尾の抜き出し（上限付き）が `model` に送られます。送りたくない場合は `enabled` を `false` にしてください。

### 表示

| `display` | 端末タイトル | ステータス行 |
|---|---|---|
| `"both"`（既定） | `π - <ラベル> - <プロジェクト名>` | `<ラベル>` |
| `"title"` | `π - <ラベル> - <プロジェクト名>` | 変更しない |
| `"status"` | 変更しない | `<ラベル>` |

- ラベルがない間、タイトルは `π - <プロジェクト名>` になります。
- プロジェクト名は作業ディレクトリの名前です。
- セッションを tree で移動したときは、ラベルを消します。次の入力で新しく生成します。
- `enabled` が `false` のときは、ラベルを表示しません。

## 制限

- 入力 1 件ごとに、モデルへの追加の呼び出しが 1 回発生します。既定はセッションのモデルです。コストを抑えるには、`model` に安いモデルを指定します。
- ラベルは要約なので、実際の作業と食い違うことがあります。食い違う場合は `prompt` を調整します。
- ラベルは保存しません。セッションを再開しても、以前のラベルは戻りません。新しい入力で生成されます。
- 端末タイトルは最後に設定された値が表示されます。同じタイトルを設定する別の拡張とは競合します。タイトルに触れさせたくない場合は `display` を `"status"` にします。
- JSON モードと print モードでは、ラベルを生成も表示もしません。
